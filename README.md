# Placar da Live

Placar informal para contabilizar presentes enviados durante uma live.

- Rosa vermelha: Lula +1
- Rosa branca: Flávio Bolsonaro +1
- Quantidade, total e porcentagens calculados automaticamente.

## Importante
A versão inicial inclui botões de teste. A contagem automática de presentes reais
do TikTok exige uma integração separada com uma fonte de eventos da live.

O placar é uma enquete informal e não representa pesquisa, votação ou resultado eleitoral oficial.
